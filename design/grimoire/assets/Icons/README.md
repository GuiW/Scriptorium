Grimoire business icons — 22 SVGs taken from Lucide (ISC licence, see `LICENSE.txt`), 1.5px stroke, 24×24.

- File ink: `ink-muted` from the Parchment theme (#654f38), because an SVG shown as an `<img>` cannot inherit the colour. In code, prefer the `Icon` component, which draws the same icons in `currentColor` and therefore follows the theme.
- Business names are French: `quete` (quest, quest list), `journal` (session journal), `session` (session date or number), `pnj` (NPC contact), `faction` (faction contact), `joueurs` (players, the table), `mj` (GM role), `lieu` (a quest's location), `carte` (map, locations section), `butin` (loot, items), `pieces` (coin reward), `xp` (XP reward), `rumeur` (rumour, hearsay), `indice` (clue, discovered secret), `secret` (content hidden from players), `urgent` (urgency, deadline), `danger` (danger, failure), `reglages` (settings), `ajouter` (add a quest, an objective…), `rechercher` (search), `filtrer` (filter a list), `plus` (more actions, « plus » tab).
- In Angular: `lucide-angular` with the original Lucide names (quete = `scroll-text`, journal = `book-open`, session = `calendar-days`, pnj = `user-round`, faction = `shield`, joueurs = `users`, mj = `venetian-mask`, lieu = `map-pin`, carte = `map`, butin = `gem`, pieces = `coins`, xp = `sparkles`, rumeur = `ear`, indice = `key`, secret = `eye-off`, urgent = `flame`, danger = `skull`, reglages = `settings`, ajouter = `plus`, rechercher = `search`, filtrer = `filter`, plus = `ellipsis`), `[strokeWidth]="1.5"`.
